1. ¿Por qué la bitácora de cambios de privilegios merece más tiempo de conservación que la de consultas rutinarias?

Porque los cambios de privilegios pueden permitir o impedir el acceso a información y modificar el nivel de seguridad de la base de datos, conservar estos registros durante más tiempo facilita investigar accesos no autorizados, identificar quién otorgó o retiró permisos y reconstruir posibles incidentes, las consultas rutinarias suelen tener una utilidad operativa más limitada y pueden generar un volumen mucho mayor de registros.

2. ¿Qué control de integridad aplicarás a las bitácoras exportadas?

Aplicaré un hash SHA-256 a cada archivo exportado para poder comprobar si su contenido fue modificado después de generar la evidencia, también conservaré el archivo original, su hash, la fecha de exportación y la persona responsable, el hash permite detectar cambios en el archivo, aunque por sí solo no impide que alguien lo sustituya; por eso debe acompañarse de controles de acceso y almacenamiento protegido.

3. ¿Qué diferencia hay entre conservar una bitácora y respaldar una base de datos?

Conservar una bitácora significa mantener registros de eventos y actividades para poder consultarlos posteriormente como evidencia de auditoría, respaldar una base de datos significa crear una copia de la información y de los elementos necesarios para recuperarla ante una pérdida o falla, la bitácora permite investigar qué ocurrió, mientras que el respaldo permite recuperar los datos y continuar la operación, son medidas complementarias, pero no sustituyen una a la otra.
